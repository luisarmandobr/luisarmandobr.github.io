Bienvenido a mi formateador de textos

En la automatización se necesita diversos tipos de formateadores de texto según el lenguaje de programación: cada tecnología tiene su propio estilo para nombrar variables, funciones, constantes, atributos, selectores o datos de prueba. Por ejemplo, JavaScript y Java suelen usar camelCase, Python prefiere snake_case, CSS y HTML usan kebab-case, y las constantes se escriben en CONSTANT_CASE.
Por eso ingreso a mi formateador de textos: escribo o pego cualquier texto en la caja de entrada, elijo el botón con el formato que necesito y las funciones hacen el trabajo por mí — aplican trim a los espacios vacíos, colapsan los espacios repetidos y colocan la letra capital donde corresponde. El resultado aparece al instante en la caja de salida, listo para copiar y usar en mis scripts.

Formato: —

1. Limpieza de espacios

2. Estilos de programación

3. Texto legible

4. Datos para automatización
