MyJWT — Decoder / Encoder de JSON Web Tokens

Los JSON Web Tokens (JWT) son el estándar abierto (RFC 7519) que se usa en la automatización para autenticar APIs, validar sesiones y probar endpoints protegidos. Un JWT tiene tres partes separadas por puntos: header.payload.signature, donde header y payload viajan en Base64URL y la firma se calcula con un secret (HMAC) o con un par de llaves pública/privada (RSA / ECDSA).
Aquí puedo decodificar un token para inspeccionar sus claims y verificar su firma, o codificar/firmar un token nuevo con mi propia cabecera y payload. Todo el procesamiento ocurre 100% en este navegador: ningún token ni secret sale de este equipo.
